# 闪跳 · 开屏广告自动跳过

一个轻量的 Android 小工具：打开其他 App 时，自动点击开屏广告上的「跳过」按钮。

- 使用系统无障碍服务实现，**无需 root**
- **没有网络权限**，所有判断在本机完成，不收集任何数据
- 可自定义关键字、检测时长，可随时暂停
- 内置「最近跳过记录」，方便确认是否生效

> 仅供个人使用。请遵守各应用的服务条款，不要用于绕过付费内容或自动化刷量。

## 一、用 GitHub Actions 打包 APK（不用装 Android Studio）

本机不需要安装 JDK / Android SDK，GitHub 会免费帮你编译。

### 1. 准备仓库

1. 注册并登录 [GitHub](https://github.com)
2. 新建一个仓库（Public / Private 均可），名字随意，例如 `skipads`
3. 把本目录 `skipads/` 里的**全部内容**上传到仓库根目录
   - 网页上传：在仓库页面点 `Add file → Upload files`，把 `skipads` 文件夹里的内容拖进去
   - 或命令行：

```bash
cd skipads
git init
git add .
git commit -m "init: skipads"
git branch -M main
git remote add origin https://github.com/<你的用户名>/skipads.git
git push -u origin main
```

> 注意：`.github/workflows/build.yml` 必须一起上传，Actions 才能运行。

### 2. 等待构建

1. 打开仓库顶部的 **Actions** 标签页
2. 会看到名为 **Build APK** 的工作流自动开始运行（约 2–4 分钟）
3. 等到出现绿色 ✓

也可以在 Actions 页面左侧点 `Build APK`，再点 `Run workflow` 手动触发。

### 3. 下载 APK

1. 点进最近一次成功的工作流运行
2. 拉到页面底部 **Artifacts** 区域
3. 下载 `skipads-debug-apk.zip`，解压得到 `app-debug.apk`

把这个 APK 传到手机安装即可（需要在系统里允许「安装未知应用」）。

## 二、首次使用

1. 安装并打开「闪跳」
2. 点「去开启无障碍服务」
3. 在系统无障碍列表中找「闪跳 · 自动跳过开屏广告」，打开开关并确认
4. 回到「闪跳」，状态卡显示「无障碍服务已开启」即生效

### Android 12 及以上的「受限制的设置」

如果从浏览器、微信或文件管理器安装，系统可能不允许开启无障碍服务。按下面步骤放开：

1. 打开「闪跳」的**应用信息**（App 内按钮可直达）
2. 点右上角 ⋮ → **允许受限制的设置**（部分机型叫「允许受限制的设置」/「解除限制」）
3. 重新进入 设置 → 无障碍 → 闪跳，打开开关

## 三、使用与调参

- **启用自动跳过**：总开关。临时不想用时关掉即可，无需关闭系统无障碍服务。
- **启动后检测时长**（默认 6 秒）：打开一个 App 后，只在这段时间内查找「跳过」按钮。时间太长可能误点，太短可能来不及。
- **跳过按钮关键字**：每行一个。默认包含 `跳过`、`跳过广告`、`跳过开屏`、`跳过此广告`、`关闭广告`、`skip`、`skip ad`、`skip ads`。如果某个 App 的跳过按钮文字特殊，可以自行添加。
- **最近跳过记录**：显示时间、命中文本和包名，可清空。

判断规则（尽量降低误触）：

- 仅当前台应用切换后的检测时长内才工作
- 匹配文本必须命中关键字，且长度不超过 12 个字符
- 每次应用启动最多点击 1 次，两次尝试间隔至少 300ms
- 自动忽略系统界面、桌面、安装器、设置等包名

## 四、常见问题

**Q：为什么某些 App 没跳过？**

常见原因：

- 开屏广告是纯图片 / 视频 / 自绘控件，无障碍层里没有「跳过」文字，无法识别
- 跳过按钮的文本里不含任何关键字（可在界面里补充关键字试试）
- 点击后广告需要「上滑/摇一摇」等交互才能关闭，不属于可点击按钮
- 该 App 使用了反无障碍策略或独立窗口（少数情况）
- Android 12+ 未允许「受限制的设置」，服务实际未运行

**Q：会误点别的东西吗？**

规则限制在「刚打开某个 App 的前几秒」，并且必须命中关键字。理论上仍有极小概率点到教程页的「跳过引导」类按钮。

**Q：耗电吗？**

无障碍服务常驻是系统机制，本工具只在应用切换后的短时间内做一次节点遍历，开销很小，不会持续占用 CPU。

**Q：会上传我的数据吗？**

不会。APK 没有申请 `INTERNET` 权限，物理上无法联网。

**Q：怎么升级 / 卸载？**

重新下载新版 APK 覆盖安装即可；卸载时系统会自动关闭对应的无障碍服务。

## 五、已知限制

- 只能识别带文字（`text` 或 `contentDescription`）的「跳过」按钮
- 视频前贴片广告、应用内弹窗广告不在支持范围
- 不同厂商 ROM 对无障碍服务的保活策略不同，可能需要在电池优化里把「闪跳」设为不限制
- debug APK 使用调试签名，适合自己安装使用；如需上架应用商店需自行配置正式签名

## 六、工程结构

```
skipads/
├── .github/workflows/build.yml        # GitHub Actions 构建配置
├── app/src/main/
│   ├── AndroidManifest.xml
│   ├── java/com/hucw/skipads/
│   │   ├── MainActivity.kt            # 主界面
│   │   ├── SkipAccessibilityService.kt# 无障碍服务：监听 + 查找 + 点击
│   │   ├── SkipMatcher.kt             # 关键字匹配（纯 Kotlin）
│   │   ├── Prefs.kt                   # 设置与统计
│   │   └── SkipLogStore.kt            # 跳过记录
│   └── res/                           # 布局、字符串、图标
└── app/src/test/                      # 单元测试
```

技术栈：Kotlin 1.9.24、AGP 8.5.2、minSdk 26、targetSdk 34，无第三方网络库。
